Build a weekly ad in five steps

Choose a layout, fill the ad from the Product Catalog, make any adjustments, preview it, then print or save the finished flyer.

1 Start a flyer

  1. Choose a layout from Edit → Template / layout in the top bar.
  2. Click the date button under the ad's title to set when it goes live.
  3. Click the ▾ next to the title for New blank flyer, a saved flyer's Duplicate, or to start from a template.
  4. Click the title and type a name — that names and saves it, like Google Docs. After that, changes save automatically.

2 Add products

  1. The Product Database panel on the left is always there — drag its right edge to resize it, or click « to collapse it.
  2. Search for the product and click Add to flyer.
  3. The product goes into the next open big or small slot based on its catalog setting.
  4. You can also type a product name directly on the flyer and choose a matching suggestion.
The builder prevents the same product from being added to a flyer twice.

↔ Replace or remove an item

  • Hover an ad slot and click ↔ Replace, then find the new product in the database and click Replace item.
  • Click Remove Item in the same hover menu to clear a slot's contents but keep the empty box.
  • Click 🗑 remove box to remove the box itself from its row entirely (a + Add box tile at the end of each row adds one back).
  • Removing an item from the flyer does not delete it from the Product Database.

✎ Edit text and prices

  • Click a product name, description, price, footer message, or store detail to edit it.
  • Type a number in the text-size box to set a product name's size exactly. Auto fits long names automatically.
  • Use Center to center the product name and description; click Left to change it back.
  • Select the correct price unit, such as lb., each, or a custom unit.

☰ Manage the Product Catalog

  • Click ＋ Add product at the top of the database to open the product editor — it stays open after saving, so you can add several products in a row before closing it.
  • Every existing product edits right in the list — click its name, description, category, price, or unit to change it; it saves as soon as you click away. Click the photo to change it.
  • Click S / B to switch a product between Small ad and Big ad placement.
  • Category matters for layouts with labeled rows (like Store Circular's Fresh Produce, Pantry Savings, etc.) — clicking + on a product whose category matches a row's label drops it straight into that row instead of just the next open slot.
  • Use Import Excel / CSV for a product list. Matching names update existing products instead of duplicating them.
  • The list is sorted alphabetically by name.

＋ Overlays, the Image Library, and templates

  • Text or image overlay: in the top bar, open Edit → + Text overlay or + Image overlay to drop a free-floating box anywhere on the flyer — even on top of a product, for something like a holiday badge or a "SALE!" burst. Drag the round ⠿ handle to move it, the corner ↘ handle to resize it (it can hang off the edge of the flyer on purpose), the ↻ handle to rotate it, and the × to remove it. Use the ⬆ button to upload a picture or 📚 to pick one already saved in the Image Library. Text overlays also get a size box for their text.
  • Image Library: a second tab next to Product Database in the left panel. Upload a graphic once (it keeps real transparency, unlike a plain photo) and reuse it on any future ad instead of re-uploading it every time.
  • Templates: click 📋 Save as template under the flyer title's ▾ menu to save the current ad as a reusable starting point. To use one, open Edit → Template / layout — saved templates (plus the built-in seasonal ones) are listed there alongside the layout choices. Picking one starts a brand-new ad from it; the template itself never changes.
Overlays are also useful for the "Store Circular" layout's labeled category rows (Fresh Produce, Pantry Savings, etc.) — click a red category banner to rename it, and use the + Add box tile / 🗑 remove box to match however many items you actually have that week.

✓ Finish the ad

  1. In the bar at the top, click Preview to see the flyer without editing controls.
  2. Use Export for a PDF, PNG, or JPEG file (page size for PDF is in the same menu).
  3. Confirm it says Saved ✓ under the Save button before closing the browser.

⤓ Backup, restore, or move to another PC

  1. Click the ⚙ icon top-left for Settings, then click Download full backup under Data & backups.
  2. Keep the downloaded JSON file somewhere safe. It contains saved flyers, catalog products, photos, settings, subscribers, and the Image Library.
  3. On another installed copy, log in and click Restore from backup.
  4. Select the JSON file, review the item counts, and type RESTORE when prompted.
Important: Restoring replaces the saved database currently on that installation. Download a fresh backup first if anything on that PC must be kept.

↻ Install an update

  1. When a new version is available, a red Version available — click to install banner appears under the top bar.
  2. Click it (or open Settings → Software updates), then Download update, close the ad builder, and run the downloaded setup file.
  3. Install it over the existing copy. Saved flyers, products, photos, and settings stay in place.
Good practice: Download a full backup before a major update or before moving the app to another PC.
